Colab Quick-Run: Gemini Structured Tool Calling

Copy and paste this directly into Google Colab to test your first structured API agent call.

!pip install -q -U google-genai from google import genai from google.genai import types from pydantic import BaseModel, Field # 1. Define Structured Output Schema class LeadQualification(BaseModel): company_name: str decision_maker: bool budget_identified: bool urgency_level: str = Field(description="Low, Medium, or High") primary_pain_point: str # 2. Client Call (Requires GEMINI_API_KEY in userdata/env) client = genai.Client() prompt = "Prospect: 'Hey, I run a 25-person logistics firm. We are burning 15 hours a week manually entering delivery orders. We have $3,000 set aside to automate this immediately.'" response = client.models.generate_content( model='gemini-2.5-flash', contents=prompt, config=types.GenerateContentConfig( response_mime_type="application/json", response_schema=LeadQualification, ), ) print(response.text)
